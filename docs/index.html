  • daleq

    Job daemon for long commands

    daleq is a small local daemon that runs long commands for a coding agent: it hands back a job id at once, runs the command under watchdogs, and keeps every output and outcome on disk. Supported on macOS and Linux; Windows is experimental.

    Install Quick start Concepts Command reference Claude Code integration Security and privacy Troubleshooting

  • drawingboard

    Design and task board

    drawingboard is a local design and task board that lives inside your project and is shared by you and Claude. Everything is a plain JSON file in drawingboard/, committed with your code. The app is one binary that serves a web UI on 127.0.0.1.

    Install Quick start Concepts Command reference Claude Code integration Security and privacy Troubleshooting

  • imgcompare

    Picture review

    imgcompare is a local review page plus a CLI for comparing pictures: art directions, mockups, screenshots, icons. The reviewer marks, votes and picks in the browser; Claude reads the feedback back as Markdown or JSON. It needs Node 20+ and has no dependencies.

    Install Quick start Concepts Command reference Claude Code integration Security and privacy Troubleshooting

  • godot-pilot

    Godot test and debug harness

    GodotPilot gives Claude hands and eyes on a Godot 4.7.2 .NET project in development: the running game, the editor, and the project's configuration. It stays out of exported builds. macOS and C# only. Jev (TypeSafe AI) is its optional, paid fast eyes and classifier.

    Install Quick start Concepts Command reference Claude Code integration Security and privacy Troubleshooting

  • simq

    iOS simulator test queue

    simq is a queue for iOS simulator tests. Any number of sessions (people, scripts, Claude Code agents) submit a test run; an always-on harness runs them one per simulator, with warm DerivedData, and hands back the result. It is being folded into daleq's iOS plugin, which reads the same .simq.toml.
